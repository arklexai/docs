This page collects the limits that apply across Arklex Platform. Each section links to the page that explains the feature. On cloud, token allowances depend on your plan. See [Billing](/settings#billing). On self-hosted deployments, your operator can change the API and tracing rate limits.

---

## Scenarios

| Limit | Value |
| --- | --- |
| Scenarios written per assistant run | {scenariosPerRun} |
| Conversation history upload | {historyUploadMb} MB, `.json` or `.jsonl` |
| Scenario import file | {importFileMb} MB, `.json` or `.csv` |
| Scenario name | {scenarioNameChars} characters |
| Goal | {goalChars} characters |
| User profile | {userProfileChars} characters |
| Agent context | {agentContextChars} characters when you import or write scenarios, {agentContextEditChars} when you edit one or use the API |
| Knowledge passages per scenario | {knowledgePerScenario}, each with a name up to {knowledgeNameChars} characters and content up to {knowledgeContentChars} |
| User goal checklist items | 1 to {checklistItems}, at least one Required. Each description up to {checklistItemChars} characters. |
| Assertions per scenario | {assertionsPerScenario}, including at most one **Tool calls** assertion |

See [Scenarios](/scenarios).

## Simulations

| Limit | Value |
| --- | --- |
| Conversations per scenario | {conversationsPerScenarioMax} |
| Max turns per conversation | {maxTurnsMax} |
| Max concurrent conversations | {concurrencyMax} (default {concurrencyDefault}) |
| Conversations per simulation | {conversationsPerSimulation} |
| Trace wait time | {traceWaitMin} to {traceWaitMax} seconds (default {traceWaitDefault}) |
| Simulations pending or running at once | {freePlanConcurrentOps} on the cloud Free plan. No limit on other plans or on self-hosted. |

See [Simulations](/simulations).

| Limit | Value |

| Custom metric description | {metricDescriptionChars} characters |

## API and tool call tracing

| Limit | Value |
| --- | --- |
| API requests per key | {apiRequestsPerMinute} per minute, with bursts up to {apiRequestBurst} |
| Connection tests per key | {connectionTestsPerMinute} per minute |
| Idempotency key lifetime | {idempotencyKeyHours} hours after the first attempt completes |
| Trace requests per organization | {traceRequestsPerMinute} per minute |
| Trace data per organization | {traceMibPerMinute} MiB per minute |
| Trace request size | {traceRequestMib} MiB compressed. Uncompressed, {traceRequestMibUncompressed} MiB for protobuf and {traceRequestMibJson} MiB for JSON. |
| Spans per trace request | {spansPerTraceRequest} |
| Trace data kept per turn | {spansPerTurn} spans and {traceMibPerTurn} MiB |
| Tool call arguments, result, and error | {toolCallFieldKib} KiB, {toolCallFieldKib} KiB, and {toolCallErrorKib} KiB. Longer values are cut. |

See [API overview](/api) and [Tool call tracing](/tool-tracing).
