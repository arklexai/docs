This page collects the limits that apply across Arklex Platform. Each section links to the page that explains the feature. For token allowances by plan, see [Billing](/settings#billing).

---

## Scenarios

| Limit | Value |
| --- | --- |
| Scenarios written per assistant run | 100 |
| Conversation history upload | 256 MB, `.json` or `.jsonl` |
| Scenario import file | 10 MB, `.json` or `.csv` |
| Scenario name | 100 characters |
| Goal | 1,000 characters |
| User profile | 3,000 characters |
| Agent context | 2,000 characters |
| Knowledge passages per scenario | 5 |
| User goal checklist items | 4 |
| Assertions per scenario | 50, including at most one **Tool calls** assertion |

See [Scenarios](/scenarios).

## Simulations

| Limit | Value |
| --- | --- |

| Max concurrent conversations | 50 (default 10) |
| Conversations per simulation | 2,000 |
| Trace wait time | 10 to 300 seconds (default 60) |
| Simulations pending or running at once | 2 on the Free plan |

| Limit | Value |

| Trace requests per organization | 600 per minute |
