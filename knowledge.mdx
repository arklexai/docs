The **Knowledge** page holds the documents and websites that ground your scenarios. When you build scenarios, Arklex searches your knowledge for relevant passages and gives them to the simulated users. This makes their questions realistic and specific.

Knowledge shapes what the **simulated user** knows and asks about. It doesn't change your agent's answers. Grounding scenarios in the same material your agent relies on is a good way to test whether the agent stays faithful to it.

---

## Knowledge types

The page has two tabs, and it opens on **Websites**:

| Tab | Description |
| --- | --- |
| **Websites** | Web pages crawled from a domain or added one link at a time. |
| **Documents** | Files you upload. |

Each item goes through these statuses:

| Status | Meaning |
| --- | --- |
| **Pending** | Waiting to be processed. |
| **Running** | Being read and indexed. |
| **Success** | Indexed and ready to use in scenarios. |
| **Error** | Processing failed. Open the item to see why. |

Only items with **Success** status can be used to build scenarios.

## Add websites

On the **Websites** tab, you can add a whole domain or a single link.

<CardGroup cols={2}>
  <Card title="Add Domain" icon="network">
    Discover the pages under a URL, then choose which ones to add.
  </Card>

  <Card title="Add Link" icon="link">
    Add a single web page.
  </Card>
</CardGroup>

To add pages from a domain:

1. Click **Add Domain**.
2. Enter the **Domain URL** and the **Number of Links to Crawl** (1 to 1,000, default 50). Optionally add **Tags** and choose a **Folder**.
3. Click **Add Domain**. Arklex starts discovering pages. Discovery only follows links that start with the URL you entered, and it skips links to files such as PDFs and images.
4. When the domain shows **Success**, click **Review URLs**.
5. Select the pages you want and click **Add N Pages**.

The tab has two tables. **Domains** lists your domain discoveries. **Links** lists the pages you added, from a domain or one at a time. Deleting a domain from the **Domains** table removes only the discovery. Pages you already added from it stay under **Links**.

## Add documents

On the **Documents** tab, click **Upload Document**. Select one or more files, or drag them into the dialog. Optionally add **Tags** and choose a **Folder**, then confirm the upload.

Supported formats: PDF, DOC, DOCX, TXT, MD, CSV, JSON, XLS, XLSX, PPTX, JPG, JPEG, and PNG. Each file can be up to 10 MB. Arklex reads the text in images and PowerPoint files with OCR, so text-based PDFs work better than scans.

The documents table shows each document's name, tags, status, and when it was last updated.

## Organize with folders

The folder panel next to the tabs shows **All items**, **Unfiled**, and your **Folders**.

- **Create a folder**: click **+** next to **FOLDERS**. If a folder is selected, the new folder goes inside it. Folders can be up to six levels deep.
- **Filter by folder**: click a folder to show only its items. Turn **Include subfolders** on or off to include or exclude items in subfolders.
- **File new items**: choose a **Folder** when you add knowledge. If you leave it as **No folder**, the item goes to **Unfiled**.
- **Move items**: select items and click **Move to folder**, or drag rows onto a folder. An item lives in one folder at a time.
- **Rename or delete a folder**: use the pencil and trash icons on the folder. When you delete a folder, you choose whether to keep its contents (moved up a level) or delete the folder and everything under it. Deleting folders never deletes your documents.

## Find and manage knowledge

**Search**: the search box matches item names and document text.

**Filter**: click **Filter** to narrow by status or tag.

**Tags**: add tags when you add knowledge, or later with **Edit tags** in an item's menu. Tags also filter the list of documents when you choose knowledge for scenarios.

**Bulk actions**: select rows with their checkboxes to **Reprocess**, **Tag**, **Move to folder**, or **Delete** them together. Your selection is kept as you move between pages.

**View an item**: click a row to open its detail page. It shows the item's status, when it was added, its tags, folder, and source, plus an AI summary of what it covers. When the status is **Success**, you can click **Edit** to change the extracted content. Saving re-indexes the item.

**Rename**: choose **Rename** in an item's menu. Only the name shown in Arklex changes.

**Reprocess**: re-reads the file or re-crawls the page. Use it to pick up changes to a web page, or to retry an item that failed. Reprocessing replaces any content you edited by hand. Arklex doesn't re-crawl pages automatically.

**Delete**: choose **Delete** in an item's menu, on its detail page, or from the bulk actions. Deleting frees the item's knowledge tokens.

If an item shows **Error**, open it to see why it failed. For example, Arklex couldn't extract any text, or your plan's knowledge allowance is used up. Fix the cause, then click **Reprocess**.

## Use knowledge in scenarios

You choose knowledge when you build scenarios with the assistant. Select **My whole knowledge base** to search everything, or **Choose documents** to pick specific items. You can filter the list by tag. See [Scenarios](/scenarios#build-with-the-assistant).

Each scenario stores a copy of the passages it uses. Later edits, reprocessing, or deletion don't change scenarios you've already saved, or their simulations. A deleted item just isn't found for new scenarios.

Grounding scenarios in your knowledge supports three kinds of testing:

- **Faithfulness testing**: check that the agent's answers match what a knowledgeable user would expect from your documents.
- **Grounded evaluation**: make sure the agent doesn't make up information that contradicts the documents the user has access to.
- **Edge-case coverage**: give simulated users specific product specs, pricing tables, or policy details that reveal gaps in what your agent knows.

## FAQ

<AccordionGroup>
  <Accordion title="What file formats can I upload?">
    PDF, DOC, DOCX, TXT, MD, CSV, JSON, XLS, XLSX, PPTX, JPG, JPEG, and PNG, up to 10 MB per file. If a document fails, check that it isn't password-protected and contains real text rather than a scanned image.
  </Accordion>

  <Accordion title="Does adding a domain index every page on the site?">
    No. **Add Domain** discovers up to the number of pages you set, under the URL you enter. You then choose which pages to add. **Add Link** adds only the single page you provide.
  </Accordion>

  <Accordion title="How do I refresh a web page that changed?">
    Click **Reprocess** on the page. Arklex doesn't re-crawl automatically.
  </Accordion>

  <Accordion title="Can I use one knowledge item in many scenarios?">
    Yes. A single document or web page can ground any number of scenarios.
  </Accordion>

  <Accordion title="Does knowledge count toward my plan?">
    Yes. Indexed knowledge uses knowledge tokens, which have a fixed limit on every plan. Deleting items frees their tokens. See [Settings](/settings#billing).
  </Accordion>
</AccordionGroup>
